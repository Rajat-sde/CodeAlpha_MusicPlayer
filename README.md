# CodeAlpha_MusicPlayer

A JavaScript-powered web music player interface for dynamic audio playback and audio management.

## Features
* **Audio Controls:** Play, pause, skip to previous track, and skip to next track.
* **Track Details:** Displays active song title, artist metadata, and album cover.
* **Interactive Progress Bar:** Visual track duration progress bar with seek functionality.
* **Volume Control:** Slider control to adjust dynamic audio volume.
* **Playlist Support:** Includes playlist browsing and continuous song playback.

## Tech Stack
* HTML5
* CSS3
* JavaScript (Vanilla)
